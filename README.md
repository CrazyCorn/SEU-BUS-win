# 东南大学校园接驳车查询

这是一个基于 Electron 的桌面应用程序，用于查询东南大学校园接驳车的发车时刻表。

## 环境要求

在开始之前，请确保您的电脑上已经安装了 [Node.js](https://nodejs.org/) (推荐 LTS 版本) 和 npm (通常会随 Node.js 一起安装)。

您可以在终端或命令提示符中运行以下命令来检查是否已成功安装：

```bash
node -v
npm -v
```

## 如何构建

请按照以下步骤从源代码构建此应用程序。

### 1. 克隆或下载仓库

首先，将本仓库的代码克隆或下载到您的本地计算机。

### 2. 安装项目依赖

使用终端进入项目根目录，然后运行以下命令来安装所有必需的依赖库：

```bash
npm install
```

此命令会读取 `package.json` 文件，并将所有依赖项下载到 `node_modules` 文件夹中。

### 3. 打包生成安装程序

依赖安装完成后，运行以下命令来打包生成 `.exe` 安装程序：

```bash
npm run dist
```

**重要提示：** 在 Windows 系统上，由于打包过程需要创建符号链接 (Symbolic Link)，您**必须**在一个**具有管理员权限**的终端 (如 PowerShell 或命令提示符) 中运行此命令，否则打包会失败。

### 4. 查找安装包

打包成功后，您可以在项目根目录下的 `dist` 文件夹中找到生成的安装程序。文件名类似于 `东南大学校园接驳车查询-v1.0.0.exe`。
